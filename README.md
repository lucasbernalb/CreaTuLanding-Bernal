# TIENDA REINA ARTURA
Este es un proyecto básico de ecommerce básico que se utiliza para el curso de React dentro de CODERHOUSE. La app permite ver cuadros realizados por la artista uruguaya "Andrea Bernasconi" y poder realizar un pedido o encargo de sus productos. Las ordenes y encargos se almacenan en Firebase y se manda un mail automatico a traves de EmailJS para avisar cuando llegue una orden nueva.

## Tecnologias Utilizadas:
- Vite
- React
- React-Router-DOM
- Firebase
- EmailJS
- Toastify
- Boostrap
